# annas-archive — ловушки

Сверено 2026-08-06 на батче из 14 книг.

**Локальный DNS (роутер или провайдер) может не резолвить партнёрские хосты**
`wtgadtq.org`, `hxd7ms.org` → `curl: (6) Could not resolve host`. Публичные DNS (1.1.1.1, 8.8.8.8) резолвят.
Обход: `dig +short <host> @1.1.1.1` → `curl --resolve <host>:443:<ip>`. При необходимости — патченная копия
скрипта: скопировать `aa_download.py` и добавить резолв через публичный DNS + `--resolve` в download-curl.
При `Could not resolve host` не ретраить как есть — чинить DNS.

**Повторный запрос того же md5 квоту НЕ тратит**
Дедуп выдачи URL работает (вопреки наблюдению 2026-07 в docstring `aa_download.py` — то, видимо, относилось
к завершённым скачиваниям). 15 неудачных DNS-попыток сожгли по юниту при ПЕРВОЙ выдаче URL каждого md5;
все ретраи после — бесплатны. Без этого батч выглядит как «квота сгорела, файлов нет» и провоцирует
панические ретраи.

**scidb-контент (статьи по DOI) на книжных партнёрских серверах даёт 404**
На всех `domain_index`. Статьи качать через открытый OA-маршрут (Unpaywall и подобные, обычным `curl`),
не через fast download — квоту Архива Анны не трогать.
